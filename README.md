這裡是 **Taiwan INFO 台灣資訊** 官方影片的放置處，收錄「中華民國歷史館」系列長片的完整版影片檔。

- 官網：[twinfo.huhm.cc](https://twinfo.huhm.cc)
- 中華民國歷史館（線上展覽，九大展廳）：[twinfo.huhm.cc/republicofchina/history](https://twinfo.huhm.cc/republicofchina/history)
- 歷史時間軸（全部事件依年代排列）：[twinfo.huhm.cc/republicofchina/history/timeline](https://twinfo.huhm.cc/republicofchina/history/timeline)
- 台灣新聞 Reels：[/news](https://twinfo.huhm.cc/news)｜科技 Reels：[/tech](https://twinfo.huhm.cc/tech)
- YouTube：[@taiwaninfo.huhmcc](https://www.youtube.com/@taiwaninfo.huhmcc)
- Instagram：[@taiwan.info](https://www.instagram.com/taiwan.info/)
- 聯絡：hi@mail.huhm.cc

## 使用規範（摘要）

- ❌ **不可商用**

完整說明請看 [what.md](./what.md)。

## 下載說明

影片以 Git LFS 存放。直接在 GitHub 網頁點進影片檔、按「Download raw file」即可下載；或使用：

```bash
git lfs install
git clone https://github.com/huhm-cc/twinfo-resource.git
```
