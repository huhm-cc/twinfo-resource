# Taiwan INFO 影片資源庫（twinfo-resource）

這裡是 **Taiwan INFO 台灣資訊** 官方影片的放置處，收錄「中華民國歷史館」系列長片的完整版影片檔。

- 官網：https://twinfo.huhm.cc
- Instagram：[@taiwan.info](https://www.instagram.com/taiwan.info/)
- 聯絡：hi@mail.huhm.cc

## 使用規範（摘要）

- ❌ **不可商用**
- ✅ 可以嵌入、下載影片，放到自己的平台或用於自己的內容
- ✅ 使用時**必須標注原作者「Taiwan INFO 台灣資訊」與出處**

完整說明請看 [what.md](./what.md)。

## 下載說明

影片以 Git LFS 存放。直接在 GitHub 網頁點進影片檔、按「Download raw file」即可下載；或使用：

```bash
git lfs install
git clone https://github.com/huhm-cc/twinfo-resource.git
```
